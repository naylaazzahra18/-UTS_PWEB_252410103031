<!-- Deskripsi project -->
FormMonitor yaitu website sistem informasi peternakan telur ayam yang dibuat untuk membantu pengelolaan dan pemantauan aktivutas peternakan, yang nantinya akan menampilkan informasi hasil panen telur, kondisi ayam, prediksi hasil panen dan prediksi jumlah ayam sakit

<!-- Fitur -->
Login : untuk memasukkan username dan password, ini merupakan username dan password yang saya pakai (usn: admin, pw: admin123)
Dashboard : menampilkan ringkasan fitur dan informasi peternakan
Pengelolaan : Menampilkan informasi mengenai proses pengelolaan peternakan secara spesifik meliputi beberapa alur dan pengambilan data informasi
Statistik peternakan : menampilkan informasi berupa hasil panen telur dan kondisi ayam termasuk juga beberapa prediksi yaitu berupa presentase
Logout : berfungsi untuk keluar dari sistem
